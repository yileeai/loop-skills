# 品牌手册（模板）

> `/content`、`/diagram-design` 和所有对外内容都按这一页执行。文件名保持 `LOOP品牌手册.md` 不变，内容换成你自己的品牌。下面以 LOOP 的设定为示例。

## 名字
- 品牌名：LOOP（全大写）　← 改成你的
- 一句话定位：（改成你的）

## 颜色
- 底色：纸面 `#F4F1EA`（浅底）/ 根据地黑 `#0F0E0C`（深底）
- 文字：近黑 `#14130F`
- **唯一强调色**：松绿，浅底用 `#1F5C46`，深底用 `#3CC48E`　← 改成你的
- 一张图 / 一张封面只给一个词或一个数字上强调色；不用渐变，不用第二种强调色

## 字体
- 系统字体：苹方 / 思源黑体 / 微软雅黑

## 语气与固定口播
- 语气：（例：结论先行，说人话，不卖焦虑）
- 开场：（固定开场白，一字不改）
- 结尾 / 行动：（固定结尾与引流口令，一字不改）

## 写法规则
- 工具名用官方写法（Claude、ChatGPT、Obsidian）
- 数字用阿拉伯数字
- 标题公式（四选一）：（改成你的）

## 封面规则
- 一张封面只说一件事
- 只有一个强调色词
