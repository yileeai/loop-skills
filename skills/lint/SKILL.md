# lint：根据地体检

## 硬约束
- 生成报告前**只读**，不改、不删、不重命名任何文件。
- 报告后等主人确认，才执行修复。
- 修复完成后在 `20-Wiki 知识/编译日志.md` 追加 `## [YYYY-MM-DD] lint | 修复了 N 个问题`。

## 检查项

### 1. 目录一致性
- 读 `20-Wiki 知识/知识总目录.md`，提取所有 `[[双链]]`。
- 扫描 `20-Wiki 知识/知识节点/`、`20-Wiki 知识/信息来源/`、`20-Wiki 知识/主题地图/综合研究/` 下的全部 `.md`（忽略 `_说明.md`）。
- 找出：已登记但文件不存在的条目；文件存在但未登记的页面。

### 2. 链接健康
- 扫描全库 `.md`（排除 `.obsidian/`、`10-Raw 原料/`、`90-System 系统/模板中心/`）里的 `[[双链]]`，去掉 `|别名` 和 `#标题` 后匹配文件名。
- **死链**：指向不存在的页面。**例外**：`20-Wiki 知识/主题地图/知识蓝图.md` 里的空链接是「待填格子」，归入第 7 项，不算死链。
- **孤岛页面**：知识地图中没有被任何其他页面链接的页面（`知识总目录.md` 的登记不算）。
- **缺 up 的页面**：知识地图中 frontmatter 没有 `up` 的页面。

### 3. 知识冲突
- 搜索包含 `## 知识冲突` 的页面，列出冲突双方。

### 4. 素材积压
- 统计 `10-Raw 原料/01-文章剪藏`、`02-报告论文`、`03-视频转录`、`04-客户咨询`、`05-我的逐字稿`、`06-AI对话` 中未归档的文件数。

### 5. 客户跟进
- 读取 `30-Action 行动/客户档案/` 中 `type: client` 的页面。
- 列出 `next_followup` 早于今天、且 `stage` 不是「已成交」「流失」的客户。
- 列出超过 30 天没更新（`last_updated`）的进行中客户。

### 6. 隐私检查
- 收集 `30-Action 行动/客户档案/` 中的客户文件名、`contact` 字段。
- 检查 `20-Wiki 知识/` 和 `30-Action 行动/工作成果/内容作品/` 是否出现这些名字。出现即为红灯。

### 7. 蓝图进度
- 读 `20-Wiki 知识/主题地图/知识蓝图.md`：统计矩阵全部格子中已有打法页的格数，以及框架里仍为空链接的条目。
- 统计 `观点/`、`案例/`、`打法/` 的页面数，与素材摘要数对比；若外部素材摘要远多于观点 + 案例，黄灯提醒「库在往底座长，主体没长」。
- 列出 `verified_count` ≥ 3 但还没提炼 SOP 的打法。

### 8. 成果回流
- 扫描 `30-Action 行动/工作成果/` 下 `type: work` 的页面（忽略 `_说明.md`）。
- 列出 `WIPstatus` 不是 `active`、且没有 `harvested` 字段的成果：已定稿但还没回流。
- 列出 `harvested` 早于 `last_updated` 的成果：回流后又改过，可能有新东西。

### 9. 大文件与公开展示
- 用 `git ls-files` 或扫描全库，找出视频 / 音频 / 剪辑工程文件（`.mp4 .mov .mkv .avi .m4a .wav .mp3 .draft` 等）和单个超过 20MB 的文件：出现即红灯，建议移出库外，只留链接。
- 媒体账号：`30-Action 行动/媒体账号/` 中 `status` 不是「筹备中」、但「数据记录」超过 35 天没新行的账号，黄灯提醒回填数据。

## 报告格式

```markdown
## 🩺 根据地体检报告 — YYYY-MM-DD

### ✅ 绿灯
- …

### ⚠️ 黄灯
- **N 个孤岛页面**：[[…]] — 建议挂到 [[…]]
- **N 个未登记页面**：[[…]]
- **素材积压**：01 文章 x 份 / 02 报告 x 份 / 03 转录 x 份 / 04 客户咨询 x 份
- **N 位客户超过 30 天未更新**：[[…]]
- **N 份成果未回流**：[[…]] — 建议 `/loopback`
- **蓝图进度**：矩阵已填 x / 16 格；观点 x 条、案例 x 条、打法 x 页 vs 素材摘要 x 份；待填框架条目：[[…]]

### ❌ 红灯
- **N 个死链**：[[来源页]] → [[不存在的页]]
- **N 个未解决冲突**：[[…]]
- **逾期未跟进**：[[客户]]（应于 YYYY-MM-DD 跟进）
- **大文件进库**：…（建议移到本地素材盘，库里留链接）
- **隐私风险**：[[内容作品]] 出现客户名「…」

### 🛠️ 建议下一步
1. 要我自动修复未登记页面和缺 up 的页面吗？
2. 死链是补建页面，还是删除链接？
3. 素材积压建议先运行 /ingest（或 /replay）；未回流的成果运行 /loopback。
```
